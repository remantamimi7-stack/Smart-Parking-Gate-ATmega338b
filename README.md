# Smart Parking Gate Controller (ATmega32) 

An automated parking gate management system developed for **Mansoura Robotics Hackathon 9.0 (Embedded Systems Track)**.
Awarded the **Best Member Award** .

---

## Features
- **Layered Software Architecture:** Designed clean MCAL, HAL, and Application layers.
- **Motor Control:** Bidirectional DC Motor control using L298N driver with H-Bridge.
- **IR Sensing & Boundary Logic:** Obstacle detection with departure-checking logic to eliminate double counting.
- **Capacity Display:** Real-time car count displayed on a 7-Segment display with strict input validation.

---

## Tech Stack & Hardware
- **Microcontroller:** ATmega32 (AVR)
- **Language:** Embedded C
- **IDE:** Microchip Studio
- **Peripherals:** L298N Motor Driver, DC Motor, IR Obstacle Sensors, 7-Segment Display.
